# Руководство пользователя

## Регистрация и вход

1. Открой http://127.0.0.1:8000
2. Нажми **«Зарегистрироваться»**
3. Придумай **логин** (3–50 символов, латиница/цифры/_), **почту** и **пароль** (минимум 8 символов)
4. После регистрации войди с тем же логином и паролем

## Работа с задачами

### Создать задачу
- Введи **название** (обязательно) и **описание** (необязательно)
- Нажми **«Добавить»** — задача появится вверху списка

### Редактировать задачу
- Нажми **«Редактировать»** у нужной задачи
- Поменяй название или описание в появившихся полях
- Нажми **«Сохранить»** или **«Отмена»**

### Отметить готовность
- Нажми **«Готово»** — задача станет полупрозрачной
- Нажми **«Отменить»**, чтобы вернуть обратно

### Удалить задачу
- Нажми **«Удалить»** — задача исчезнет без подтверждения

## Профиль

1. Нажми **«Профиль»** в меню
2. Можно сменить почту и/или пароль
3. Для смены пароля нужно ввести текущий пароль

## Админ-панель

Доступна только пользователям с ролью `admin`.

- **Список пользователей** — ID, логин, почта, роль, дата последнего входа, статус
- **Смена роли** — выпадающий список (user/admin)
- **Заблокировать / Разблокировать** — блокировка входа пользователю
- **Удалить** — полностью удаляет пользователя

Нельзя заблокировать или удалить самого себя.

## API

Полная документация доступна в Swagger UI:
- http://127.0.0.1:8000/docs
- http://127.0.0.1:8000/redoc

## Переключение языка

Кнопка **EN/RU** в правом верхнем углу переключает интерфейс между русским и английским.
